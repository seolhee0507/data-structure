# Array, Binary Search Tree, AVL Tree 성능 비교

## 1. 과제 개요

본 과제에서는 0부터 1,000 사이의 정수를 100번 임의 생성하여 정수 배열(Array), 이진 탐색 트리(Binary Search Tree, BST), AVL 트리에 각각 저장하고 성능을 비교하였다.

세 자료구조에는 동일한 난수를 동일한 순서로 삽입하였으며, 이미 존재하는 값은 중복으로 판단하여 삽입하지 않았다.

데이터 삽입 과정에서는 중복 확인 및 삽입 위치 탐색에 발생하는 숫자 비교 횟수를 측정하였다. 이후 추가로 생성한 50개의 탐색 대상을 이용하여 순차 탐색, BST 탐색, AVL 트리 탐색의 비교 횟수를 측정하였다.

## 2. 데이터 생성 및 저장 결과

100개의 난수를 생성한 결과 다음과 같은 결과가 나타났다.

| 항목             |   결과 |
| -------------- | ---: |
| 난수 생성 횟수       | 100회 |
| 실제 저장된 서로 다른 값 |  98개 |
| 중복으로 삽입되지 않은 값 |   2개 |

중복된 값이 2개 발생하여 실제 저장된 데이터는 98개였다. 배열, BST, AVL 트리 모두 동일한 98개의 데이터를 저장하였다.

### 2-1. 생성 과정의 비교 횟수

| 자료구조     | 삽입 비교 횟수 |
| -------- | -------: |
| Array    |   4,792회 |
| BST      |     591회 |
| AVL Tree |     526회 |

배열은 새로운 값이 생성될 때마다 기존 배열의 첫 번째 원소부터 마지막 원소까지 순차적으로 비교하여 중복 여부를 확인한다. 따라서 기존에 저장된 데이터가 많을수록 비교 횟수가 증가한다.

BST는 루트 노드부터 시작하여 새로운 값이 현재 노드보다 작은지 큰지 확인하면서 삽입 위치를 찾는다. 배열보다 적은 비교 횟수로 삽입할 수 있었다.

AVL 트리 역시 BST와 같은 방식으로 삽입 위치를 탐색하지만, 삽입 후 회전을 통해 균형을 유지한다. 이번 실험에서는 AVL 트리의 삽입 비교 횟수가 526회로 세 자료구조 중 가장 적게 측정되었다.

## 3. 자료구조의 크기 및 높이

모든 데이터의 삽입이 완료된 후 각 자료구조의 크기와 높이를 측정하였다.

| 자료구조        | 크기 또는 높이 |
| ----------- | -------: |
| Array 길이    |       98 |
| BST 높이      |       12 |
| AVL Tree 높이 |        8 |

배열에는 총 98개의 원소가 저장되었다.

BST의 높이는 12였으며, AVL 트리의 높이는 8이었다. 두 트리는 동일한 데이터를 저장하고 있지만 구조적인 차이로 인해 높이가 다르게 나타났다.

BST는 삽입 순서에 따라 트리의 균형이 달라진다. 데이터가 한쪽으로 치우쳐 삽입되면 높이가 증가할 수 있다.

반면 AVL 트리는 각 노드의 왼쪽과 오른쪽 서브트리의 높이 차이를 일정 범위로 유지하도록 회전하기 때문에 상대적으로 균형 잡힌 구조를 형성한다.

이번 실험에서도 AVL 트리가 BST보다 4단계 낮은 높이를 기록하였다.

## 4. 탐색 데이터 및 탐색 결과

데이터 삽입이 완료된 후 0부터 1,000 사이의 정수 50개를 추가로 생성하여 탐색 대상으로 사용하였다.

동일한 탐색 대상에 대하여 배열, BST, AVL 트리에서 각각 탐색을 수행하였다.

### 4-1. 탐색 결과 요약

| 항목       |  결과 |
| -------- | --: |
| 전체 탐색 횟수 | 50회 |
| 탐색 성공 횟수 |  4회 |
| 탐색 실패 횟수 | 46회 |

50회의 탐색 중 실제 데이터가 존재하여 탐색에 성공한 횟수는 4회였으며, 나머지 46회는 탐색에 실패하였다.

세 자료구조는 동일한 데이터를 저장하고 동일한 탐색 대상을 사용했기 때문에 탐색 성공 및 실패 결과도 동일하게 나타났다.

### 4-2. 탐색 비교 횟수

| 탐색 방법             | 총 비교 횟수 | 평균 비교 횟수 |
| ----------------- | ------: | -------: |
| Sequential Search |  4,829회 |   96.58회 |
| BST Search        |    409회 |    8.18회 |
| AVL Search        |    339회 |    6.78회 |

**순차 탐색(Sequential Search)**

배열은 정렬되지 않은 상태이므로 탐색 대상이 존재하는지 확인하기 위해 첫 번째 원소부터 차례대로 비교해야 한다.

탐색에 성공하면 해당 값을 찾을 때까지 비교하고, 탐색에 실패하면 배열의 마지막 원소까지 모두 확인해야 한다.

이번 실험에서는 총 4,829회의 비교가 발생했으며 평균 비교 횟수는 96.58회였다.

**이진 탐색 트리(BST Search)**

BST는 루트 노드부터 탐색을 시작하고, 탐색 대상이 현재 노드보다 작으면 왼쪽으로, 크면 오른쪽으로 이동한다.

배열처럼 모든 데이터를 확인하지 않고 트리의 구조를 이용하여 탐색 범위를 줄일 수 있다.

이번 실험에서는 총 409회의 비교가 발생했으며 평균 비교 횟수는 8.18회였다.

**AVL 트리(AVL Search)**

AVL 트리는 일반적인 BST와 탐색 방법은 동일하지만, 삽입 과정에서 균형을 유지하기 때문에 트리의 높이가 상대적으로 낮다.

이번 실험에서는 총 339회의 비교가 발생했으며 평균 비교 횟수는 6.78회로 세 가지 방법 중 가장 적은 비교 횟수를 기록하였다.

## 5. 성능 비교 및 분석

### 5-1. 생성 과정의 성능 비교

데이터 삽입 과정에서 발생한 비교 횟수는 배열 4,792회, BST 591회, AVL 트리 526회였다.

배열은 저장된 모든 원소를 순차적으로 확인해야 하므로 중복 확인에 많은 비교가 필요했다.

BST와 AVL 트리는 트리 구조를 이용하여 삽입 위치를 탐색하기 때문에 배열보다 적은 비교 횟수가 발생하였다.

특히 AVL 트리는 균형을 유지하면서 삽입하기 때문에 이후 탐색에서도 효율적인 구조를 형성할 수 있었다.

다만 이번 과제의 비교 횟수는 저장된 데이터와 새로 삽입하려는 데이터 사이의 비교만 측정하였으며, AVL 트리의 높이 계산과 균형 인수 확인 및 회전 과정은 포함하지 않았다.

### 5-2. BST와 AVL 트리의 높이 차이

이번 실험에서 BST의 높이는 12, AVL 트리의 높이는 8이었다.

BST는 데이터가 삽입되는 순서에 따라 트리의 구조가 달라지며, 한쪽 방향으로 노드가 치우치면 높이가 증가한다.

반면 AVL 트리는 LL, RR, LR, RL 회전을 통해 불균형을 해결하고 트리의 균형을 유지한다.

따라서 동일한 98개의 데이터를 저장했음에도 AVL 트리가 BST보다 낮은 높이를 갖게 되었다.

트리의 높이는 탐색 과정에서 방문할 수 있는 노드의 최대 깊이와 관련이 있다. 일반적으로 높이가 낮을수록 탐색에 필요한 비교 횟수가 줄어든다.

### 5-3. 탐색 성능 비교

탐색 평균 비교 횟수를 비교하면 배열은 96.58회, BST는 8.18회, AVL 트리는 6.78회였다.

AVL 트리는 배열보다 평균 비교 횟수가 크게 적었으며, BST와 비교해도 더 적은 비교 횟수를 기록하였다.

구체적으로 AVL 트리의 평균 비교 횟수는 BST보다 1.40회 적었다.

이는 AVL 트리가 BST보다 낮은 높이를 유지했기 때문에 탐색 과정에서 방문하는 노드 수가 줄어든 결과로 볼 수 있다.

또한 이번 실험에서는 50회의 탐색 중 46회가 실패한 탐색이었다. 실패한 탐색은 배열의 경우 98개 원소를 모두 확인해야 하지만, BST와 AVL은 탐색 경로를 따라가다가 더 이상 이동할 노드가 없으면 탐색을 종료할 수 있다.

이러한 구조적인 차이가 전체 비교 횟수의 차이로 나타났다.

### 5-4. 최종 결론

이번 실험을 통해 배열, BST, AVL 트리의 자료구조적 특징에 따라 데이터 삽입과 탐색 성능이 달라진다는 것을 확인하였다.

배열은 구현이 간단하고 데이터의 최초 생성 순서를 유지할 수 있지만, 중복 확인과 탐색 과정에서 순차적으로 비교해야 하므로 비교 횟수가 많았다.

BST는 트리 구조를 이용하여 배열보다 효율적인 삽입과 탐색이 가능했지만, 데이터의 삽입 순서에 따라 트리의 높이가 달라지는 단점이 있었다.

AVL 트리는 회전을 통해 트리의 균형을 유지하기 때문에 BST보다 낮은 높이를 형성하였으며, 이번 실험에서도 가장 적은 삽입 및 탐색 비교 횟수를 기록하였다.

최종적으로 이번 실험에서는 AVL 트리가 가장 효율적인 탐색 성능을 보여주었다. 이를 통해 트리의 높이와 균형 상태가 탐색 성능에 중요한 영향을 미친다는 것을 확인할 수 있었다.

다만 AVL 트리는 균형을 유지하기 위한 추가적인 회전 및 높이 관리 작업이 필요하므로, 실제 프로그램에서는 삽입과 탐색의 빈도 및 관리 비용을 함께 고려하여 적절한 자료구조를 선택해야 한다.
