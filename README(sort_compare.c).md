# 삽입 정렬과 쉘 정렬의 비교 횟수 분석

## 1. 과제 목적

동일한 무작위 정수 데이터를 대상으로 삽입 정렬(Insertion Sort)과 두 가지 쉘 정렬(Shell Sort)을 수행하고, 정렬 과정에서 발생하는 데이터 값끼리의 비교 횟수를 측정한다.

쉘 정렬은 다음 두 가지 간격 수열을 사용한다.

1. **Shell's Original Sequence**: `n/2`부터 시작하여 간격을 절반씩 줄이는 방식
2. **Knuth Sequence**: `h(k+1) = 3h(k) + 1` 점화식으로 생성한 간격을 큰 값부터 작은 값 순서로 적용하는 방식

실험을 통해 데이터 크기와 간격 수열에 따라 비교 횟수가 어떻게 달라지는지 분석한다.

## 2. 실험 환경 및 데이터 생성

- 프로그래밍 언어: C
- 데이터 자료형: `int`
- 데이터 값 범위: 0 ~ 1,000,000
- 데이터 크기: 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / 20,000
- 정렬 순서: 오름차순
- 난수 생성: 고정 시드 `2026`을 사용하는 32비트 LCG
- 비교 횟수 자료형: `unsigned long long`

각 데이터 크기마다 원본 무작위 배열을 한 번 생성한 다음, `memcpy()`를 이용해 세 개의 배열에 동일하게 복사했다. 따라서 세 정렬 알고리즘은 각 데이터 크기에서 완전히 동일한 입력 데이터를 사용한다.

고정 시드를 사용하므로 동일한 C 정수 연산 환경에서는 실험 데이터를 재현할 수 있다.

## 3. 정렬 알고리즘 구현

### 3.1 삽입 정렬 (Insertion Sort)

두 번째 원소부터 시작하여 현재 원소를 `key`에 저장한다. 정렬된 왼쪽 영역에서 `key`보다 큰 원소를 한 칸씩 오른쪽으로 이동시키고, 빈 위치에 `key`를 삽입한다.

- 이미 정렬된 영역의 원소와 `key`를 비교한다.
- `arr[j] > key`와 같은 데이터 비교가 실행될 때 비교 횟수를 1 증가시킨다.
- `j >= 0`과 같은 인덱스 및 반복 조건 검사는 비교 횟수에 포함하지 않는다.

삽입 정렬은 평균 및 최악의 경우 시간 복잡도가 O(n²)이므로 무작위 데이터의 크기가 커질수록 비교 횟수가 빠르게 증가한다.

### 3.2 쉘 정렬 - 기본 간격 (Shell's Original Sequence)

간격을 `n/2`에서 시작하여 정수 나눗셈으로 절반씩 감소시킨다. 각 간격에 대해 간격만큼 떨어진 원소들을 삽입 정렬 방식으로 정렬한다.

예를 들어 데이터 크기가 1,000일 때 간격은 다음과 같다.

`500 → 250 → 125 → 62 → 31 → 15 → 7 → 3 → 1`

마지막 간격이 1이므로 전체 배열이 최종적으로 오름차순 정렬된다.

### 3.3 쉘 정렬 - Knuth 간격 수열 (Knuth Sequence)

Knuth 간격 수열은 다음 점화식으로 생성한다.

- 최초 간격: `h(1) = 1`
- 다음 간격: `h(k+1) = 3h(k) + 1`

수열은 다음과 같다.

`1, 4, 13, 40, 121, 364, 1093, 3280, 9841, ...`

데이터 크기보다 작은 간격 중 가장 큰 값을 선택하고, 큰 간격부터 역순으로 적용한다. 예를 들어 데이터 크기가 1,000이면 다음 간격을 사용한다.

`364 → 121 → 40 → 13 → 4 → 1`

마지막 간격은 항상 1이다.

## 4. 비교 횟수 측정 방법

비교 횟수는 **정렬 과정에서 배열의 데이터 값끼리 비교한 횟수**만 센다.

예를 들어 삽입 정렬의 다음 코드를 기준으로 한다.

```c
while (j >= 0) {
    comparisons++;       // 데이터 비교 직전에 1 증가
    if (arr[j] > key) {
        ...
    } else {
        break;
    }
}
```

`arr[j] > key`가 실행될 때마다 1회로 계산한다. 비교 결과가 참인지 거짓인지는 관계없다.

다음 항목은 비교 횟수에 포함하지 않는다.

- 반복문의 인덱스 및 종료 조건 검사 (`i < n`, `j >= gap` 등)
- 난수 데이터 생성
- 배열 복사
- 정렬 완료 후 수행하는 오름차순 검증

정렬 결과는 `is_sorted()` 함수로 검사했다. 세 알고리즘의 결과가 모두 오름차순이면 `Verification : PASS`를 출력한다.

## 6. 결과 분석

### 6.1 데이터 크기 증가에 따른 비교 횟수 변화

삽입 정렬의 비교 횟수는 데이터 크기가 증가하면서 매우 빠르게 증가했다. 예를 들어 데이터가 1,000개일 때 252,765회였지만, 20,000개에서는 100,373,228회로 증가했다.

데이터 크기가 2배가 되면 삽입 정렬의 비교 횟수도 대체로 약 4배 수준으로 증가하는 경향을 보인다. 이는 무작위 데이터에서 삽입 정렬이 평균적으로 O(n²)의 비교 작업을 수행하기 때문이다. 삽입 정렬은 원소를 하나씩 정렬된 영역에 삽입하므로, 뒤쪽에 있는 원소가 앞쪽의 여러 원소와 비교될 수 있다.

반면 쉘 정렬은 큰 간격으로 떨어진 원소들을 먼저 정렬한다. 이 과정에서 원소들이 최종 위치에 더 가까워지므로 마지막 간격 1에서 수행하는 작업량이 줄어든다. 실험에서도 두 쉘 정렬의 비교 횟수는 삽입 정렬보다 훨씬 적게 나타났다.

### 6.2 삽입 정렬과 쉘 정렬의 성능 차이

데이터 크기 20,000에서 삽입 정렬은 100,373,228회의 비교를 수행했다. 같은 데이터에 대해 기본 간격 쉘 정렬은 613,668회, Knuth 간격 쉘 정렬은 545,913회만 수행했다.

즉, 이 실험에서 두 쉘 정렬은 삽입 정렬보다 훨씬 적은 데이터 비교를 수행했다. 이는 쉘 정렬이 큰 간격의 부분 정렬을 먼저 수행하여 원소의 이동 거리를 줄이고, 마지막 간격 1에서의 삽입 정렬 부담을 낮추기 때문이다.

### 6.3 기본 간격과 Knuth 간격 수열의 성능 차이

측정한 모든 데이터 크기에서 Knuth 간격 수열의 비교 횟수가 기본 간격 수열보다 적었다.

예를 들어 데이터 크기 20,000에서 기본 간격 방식은 613,668회, Knuth 방식은 545,913회였다. Knuth 방식은 기본 간격 방식보다 67,755회 적게 비교했다.

이번 실험에서 Knuth 방식이 더 적은 비교 횟수를 보인 이유는 간격이 줄어드는 순서와 크기가 부분 배열의 정렬 상태에 영향을 주기 때문이다. 기본 간격은 매 단계에서 단순히 절반으로 줄어드는 반면, Knuth 수열은 `1, 4, 13, 40, 121, ...`처럼 3배에 1을 더하는 구조를 가진다. 이 간격들은 서로 다른 거리의 원소들을 단계적으로 정렬하여 원소가 최종 위치에 가까워지도록 돕는다.

다만 쉘 정렬의 성능은 입력 데이터와 간격 수열에 따라 달라진다. 따라서 이번 결과만으로 Knuth 수열이 모든 데이터와 모든 환경에서 항상 더 빠르다고 일반화할 수는 없다.

### 6.4 간격 수열이 쉘 정렬 성능에 영향을 미치는 이유

쉘 정렬에서 간격은 어떤 원소끼리 먼저 비교하고 이동시킬지를 결정한다.

- 간격이 크면 멀리 떨어진 원소를 먼저 이동시킬 수 있어 큰 위치 차이를 빠르게 줄일 수 있다.
- 간격이 너무 작거나 특정 간격들이 비효율적으로 구성되면 일부 원소가 충분히 이동하지 못해 후속 정렬 단계의 비교가 늘어날 수 있다.
- 간격을 여러 단계로 줄이면 전체 배열이 점진적으로 정렬된다.
- 마지막 간격 1은 일반 삽입 정렬과 같은 역할을 하며, 앞 단계에서 배열이 어느 정도 정렬되어 있을수록 비교 횟수가 감소한다.

따라서 쉘 정렬에서는 간격의 개수뿐 아니라 각 간격의 크기와 적용 순서가 중요하다.

## 7. 결론

이번 실험에서는 데이터 크기가 증가할수록 삽입 정렬의 비교 횟수가 급격하게 증가하는 것을 확인했다. 쉘 정렬은 큰 간격을 이용해 원소를 먼저 이동시키므로 삽입 정렬보다 훨씬 적은 비교 횟수로 정렬을 수행했다.

또한 이번 실험 데이터에서는 Knuth 간격 수열을 사용한 쉘 정렬이 기본 간격 수열을 사용한 쉘 정렬보다 모든 데이터 크기에서 비교 횟수가 적었다. 이를 통해 쉘 정렬의 성능은 알고리즘 자체뿐 아니라 간격 수열의 선택에도 영향을 받는다는 점을 확인했다.

결론적으로 데이터가 커질수록 삽입 정렬보다 쉘 정렬이 비교 횟수 측면에서 유리했으며, 본 실험에서는 Knuth 간격 수열이 가장 적은 비교 횟수를 기록했다.
